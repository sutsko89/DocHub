# EW.DocHub — отчёт этапа M7: обновления, упаковка, паритет = CP2

Ветка `qt-migration`, база — M6 `1c131f4`.
План: `DocHub_qt_migration_2.28.2_rev1.md`, раздел «M7 — Обновления,
упаковка, паритет = контрольная точка CP2 (M)» и И.2 (канал обновлений).
Среда разработки: Linux-песочница, Python 3.12.16, PySide6/Qt 6.12.0,
Xvfb :99 (pytest/smoke) / offscreen (диагностика — см. W-3 в stage-notes).
Приёмка Windows — по runbook `qt-migration-M7-windows-runbook.md`
(К-5, К-6, К-8, замеры Е) — «не проверено» до прогона.

## 1. Подзадачи этапа (по составу M7)

1. **Флейвор-ассеты обновлений (И.2)** — `updater.parse_release_payload`
   собирает ассеты обоих флейворов; `installer_asset_for_flavor` — выбор
   своего; `run_installer_command` переезжает в GUI-free ядро.
2. **UI обновлений на Qt** — `updater_qt.py` (`UpdateControllerQt`):
   автопроверка (QTimer 2200 мс), ручная проверка с guard, диалог
   результата, окно скачивания (прогресс/отмена), SHA-256, тихая
   установка и закрытие приложения.
3. **Карточка «Обновления»** на странице «Настройки» — статус версии
   с суффиксом «-qt», кнопка проверки, чекбокс автопроверки.
4. **Интеграция каркаса** — `main_qt`: `update_flow` до построения
   страниц (Tk-контракт), стартовый таймер автопроверки.
5. **Сборка** — финализация `EWDochub_qt.spec` (полный набор шаблонов),
   новый `installer_qt.iss` (те же AppId/AppMutex), `bump_version.py`
   на оба установщика.
6. **CI/release** — `ci.yml`: smoke_qt + контрольная сборка Qt;
   `release.yml`: обе сборки, подпись, SHA256SUMS.txt обоих ассетов.
7. **smoke_qt Г #17** — блок проверок обновлений (Tk-паритет 2.15/2.18/2.19
   + флейвор-выбор), 21 новая проверка.
8. **Тесты** — `test_updater.py` +8 (флейвор), `test_updater_qt.py`
   новый (35).
9. **Документы** — отчёт (таблица паритета), Windows-runbook, stage-notes.

## 4. Что сделано

**Новые файлы**

- `updater_qt.py` — `UpdateControllerQt` + окно скачивания: дословный
  перенос контрактов Tk-контроллера (три рубильника автопроверки, guard,
  диалог «Обновить сейчас/Открыть страницу/Позже», окно прогресса с
  отменой — закрытие окна = отмена, дренаж очереди за тик, деструктивное
  подтверждение U7, снимок реестра BKUP-1, `call_later(500, close)`);
  отличие — выбор ассета по флейвору (И.2) и статус версии «2.28.2-qt».
  Модуль не импортирует updater_controller (там tkinter — в Qt-сборке
  стек исключён).
- `installer_qt.iss` — установщик Qt-сборки: те же AppId/AppMutex
  (обновление Tk 2.28.2 → Qt в ту же папку), `EW.DocHub-qt.exe`,
  ассет `*-qt-setup.exe`, [InstallDelete] очищает старую сборку,
  пользовательские данные %APPDATA% не затрагиваются.
- `tests/test_updater_qt.py` — 35 тестов: гейты автопроверки, guard и
  кнопка, диалоги (флейвор-ассет → «Обновить сейчас»; нет ассета своего
  флейвора → страница, чужой не скачивается), скачивание-воркер
  (progress/phase/done/cancelled/error, SHA-256, битый файл удаляется,
  чужой хост SEC-1), окно прогресса (МБ/фаза/отмена), установка
  (деструктивное подтверждение, снимок реестра, отложенное закрытие),
  карточка настроек (суффикс версии, чекбокс → settings.json).

**Изменённые файлы**

- `updater.py` — ядро: карта `installers` в `parse_release_payload`
  (Tk-контракт `installer_url` сохранён), `parse_installer_name`,
  `installer_asset_for_flavor`, `run_installer_command` (переезд из
  Tk-контроллера). Allowlist/лимиты/формат SHA256SUMS/таймауты — без
  изменений (запрет 5).
- `updater_controller.py` — `run_installer_command` делегирует ядру
  (имя модуля — контракт подмен в smoke/тестах); неиспользуемые
  `subprocess`/`sys` убраны.
- `settings_page_qt.py` — карточка «Обновления» (Tk-порядок карточек),
  `toggle_auto_update_check` через `app.save_setting`.
- `main_qt.py` — `update_flow` до построения страниц;
  `QTimer.singleShot(2200, maybe_auto_check)` — Tk `root.after(2200)`.
- `EWDochub_qt.spec` — datas: полный набор шаблонов .docx (M7-финализация).
- `tools/bump_version.py` — синхронизация версии на оба установщика.
- `.github/workflows/ci.yml` — smoke_qt (Linux Xvfb + Windows) и
  контрольная сборка Qt на Windows (риск 5); таймаут 35 мин.
- `.github/workflows/release.yml` — обе сборки, подпись обоих exe и
  setup, SHA256SUMS.txt с обеими строками, текст релиза про два флейвора.
- `smoke_qt.py` — блок Г #17 (21 проверка): виджеты карточки, суффикс
  версии, разбор релиза, флейвор-выбор, чужой флейвор недоступен,
  троттлинг, env-глушилка, run_installer + отложенное закрытие,
  download-воркер (progress/phase/done), окно прогресса/отмена.
- `tests/test_updater.py` — +8 тестов флейвора; подмена платформы в
  `test_run_installer_command_requires_windows` следует за переездом

## 6. Инцидент окружения W-3 (не дефект продукта)

После пересоздания песочницы стейл-лок `/tmp/.X99-lock` прошлой сессии
мешал подъёму Xvfb; Qt молча откатывался в offscreen, где QTableView
после `reset()` модели автополирует первую строку — click-toggle тест
реестра (`test_click_toggle_clears_and_restores_selection`) детерминированно
падал. Диагностика: на Xvfb тот же код проходит (реестр открывается без
выделения — Tk-паритет); на offscreen — особенность платформы Qt.
Хелпер `scripts/dochub_pytest.sh` (среда песочницы, вне репозитория)
укреплён: очистка стейл-лока, ожидание подъёма, громкая ошибка вместо
тихого offscreen-отката. Продуктовый код не менялся; на Windows-сборку
не влияет. Подробно — `docs/qt-migration-stage-notes.md` (W-3).

## 7. Отклонения от Tk и решения этапа

- **Окно скачивания** — QDialog немодальный (Tk CTkToplevel transient —
  тоже немодальный); закрытие крестиком = отмена (тот же контракт).
- **Диалог результата** — каркасный `app.choice` (QMessageBox) вместо
  Tk `_choice_dialog`; тексты и порядок кнопок — Tk-паритет.
- **Статус версии** — с суффиксом «-qt» на карточке настроек (И.2 —
  «отображается как 2.29.0-qt»); Tk показывает числовую версию.
- **Периодический QTimer вместо after()-цепочки** — регрессия 2.18.0
  (Tk: перевешивание after после каждого события) в Qt структурно
  невозможна; семантика «осушить очередь за тик, остановка на
  терминальном событии» сохранена и покрыта тестами.
- **Карточка «Обновления»** — последняя недостающая карточка Tk-страницы
  настроек перенесена (заметка M6 закрыта).
