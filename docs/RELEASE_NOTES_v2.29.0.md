# EW.DocHub v2.29.0 — текст релиза (вставить в тело GitHub Release)

Установщики Windows (2.29.0, два флейвора):

* **EW.DocHub-2.29.0-qt-setup.exe** — основная сборка на Qt (PySide6):
  первая Qt-версия программы. Все страницы прежней версии — карточка
  контрагента, договор, доп. соглашение, спецификация, реестр, настройки,
  импорт пакета, корзина, сверка, канал обновлений. Окно — с обычной
  системной рамкой Windows (нативные перетаскивание, прилипание,
  Snap Layouts).
* **EW.DocHub-2.29.0-setup.exe** — прежняя Tk-сборка (откатная линия;
  канал Tk заморожен на 2.28.2, установка остаётся для возврата).

Контрольные суммы SHA-256 обоих ассетов — в файле `SHA256SUMS.txt`
рядом с установщиками. Автообновление скачивает ассет своего флейвора
и сверяет сумму по `SHA256SUMS.txt`; чужой флейвор не скачивается.
Оба установщика имеют один AppId: обновление Tk 2.28.2 → Qt 2.29.0
ставится поверх в ту же папку, реестр, настройки и ключ DaData
сохраняются (данные — в `%APPDATA%\DogovorGenerator`, не в папке
программы). Возврат на Tk-сборку — установкой `EW.DocHub-2.28.2-setup.exe`
с релиза 2.28.2 поверх: база после Qt-сессии читается Tk-сборкой.

Требования: Windows 10/11 x64; Word или LibreOffice — для открытия
готовых `.docx`; интернет — только для автозаполнения по DaData и
проверки обновлений (отключается переменной `EWDOCHUB_NO_UPDATE_CHECK=1`).
После установки в программе нет ни данных, ни ключей — реестр пуст,
ключ DaData вводится в «Настройках».

Проверка новых версий — «Настройки → Обновления» (кнопка или раз в сутки).
Запросы — только к `api.github.com` и `objects.githubusercontent.com`,
без телеметрии.

Установщик не подписан сертификатом: SmartScreen может показать
«неизвестный издатель» — «Подробнее → Выполнить в любом случае».
Подробнее о миграции интерфейса — CHANGELOG (запись 2.29.0) и отчёты
этапов в `docs/`.
